# MSc Advanced Object-Oriented Design and Programming e-Portfolio

Welcome.

This repository supports my Advanced Object-Oriented Design and Programming module on my Master’s degree. It is a working record of how I applied secure, object-oriented and pattern-based design, and how my thinking developed during the module.

The focus is on code, design decisions, testing and reflection. The aim is to show what was done, why it was done that way and what could be improved.

---

## Repository Structure

📁 01 – Module Reflection  
Week-by-week reflections on object-oriented design, patterns, testing and AI-aware architectures.

📁 02 – Coding Exercises  
Programming tasks focused on secure coding, thread-safe Python and advanced object-oriented principles and design patterns.

📁 03 – Testing  
Unit tests, mocking examples and notes on AI-assisted testing tools, with attention to how testing supports software quality.

📁 04 – Case Study  
Analysis of one software architecture, including key design choices, security implications and questions about scalability and maintainability.

📁 05 – Capstone Project  
The main software project for the module, showing how design patterns and object-oriented principles support a scalable and AI-ready solution.

📁 06 – Research Notes  
Reading notes, lecture summaries and independent research that connect module topics to current software engineering and AI practice.

📁 07 – Professional Development  
Professional Development Plan, strengths, areas for improvement, future goals and actions linked to further study, certifications and applied projects.

---

## Module Learning Outcomes

Within this module and repository, I aim to show that I can:

- Apply advanced object-oriented programming principles to structure complex software.
- Design secure and scalable software architectures that are robust in realistic settings.
- Use design patterns, including Strategy, Decorator, Visitor and Abstract Factory, to create reusable and flexible code.
- Develop software that is adaptable for AI models and efficient for data science, including awareness of ideas such as a Model Registry and a Feature Store.
- Critically evaluate software engineering decisions, including pattern choice, level of abstraction and testing approach.
- Reflect on my academic and professional development and link practical work to longer-term skills and career goals.

Each folder will contain artefacts such as code, diagrams or notes. In the written e-portfolio these artefacts will be linked back to the learning outcomes.

## About This Portfolio

This repository will be updated throughout the module. New coding artefacts, testing examples, case studies and reflections will be added, and existing work may be refined.

The aim is to show technical work and also critical analysis. For each piece of work, the intention is to explain why a pattern or architecture was chosen, what worked well, where it introduced complexity and how those decisions could be improved in future projects. It also provides evidence for my Professional Development Plan by linking concrete tasks to skills like secure design, testing, ethical AI-aware software engineering and resilient problem-solving.
